# Thuật ngữ dự án

| Thuật ngữ | Ý nghĩa |
|---|---|
| PO | Purchase Order — đơn mua hàng |
| SO | Sales Order — đơn bán hàng |
| Phiếu nhập | Chứng từ ghi nhận hàng đi vào kho từ PO |
| Phiếu xuất | Chứng từ ghi nhận hàng rời kho theo SO |
| Kho xác nhận | Bước kiểm tra nghiệp vụ kho trước khi gửi kế toán |
| Kế toán duyệt phiếu kho | Bước cuối làm thay đổi tồn kho và công nợ |
| Tiền cơ sở | Đồng tiền chuẩn để quy đổi; hiện là VND |
| Tỷ giá chứng từ | Tỷ giá được chụp và lưu trên chứng từ, không thay đổi hồi tố |
| Công nợ phải thu | Số tiền khách hàng còn phải thanh toán |
| Công nợ phải trả | Số tiền còn phải thanh toán nhà cung cấp |
| Sổ biến động tồn | Lịch sử bất biến của mọi lần nhập, xuất và chuyển kho |
| Sổ tài khoản | Lịch sử thu, chi, chuyển và số dư sau mỗi giao dịch |
| Permission | Quyền thao tác dạng `module.hanh_dong` |
| ADR | Bản ghi quyết định kỹ thuật/nghiệp vụ và lý do lựa chọn |
